# Exchange

Калькулятор обменных курсов USD ↔ другая валюта. Тестовое задание.

## Стек
SwiftUI, MVVM, async/await, Decimal для денег.

## Запуск
Открыть `Exchange.xcodeproj` → ⌘R. Ничего доп. настраивать не нужно.

## Архитектура
Model (Ticker) → ViewModel (вся логика и состояние) → View (только отображение).

## Известные ограничения
API списка валют недоступен — использую fallback-список.
