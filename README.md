# Exchange

Калькулятор обменных курсов USD ↔ другая валюта. Тестовое задание.

## Стек
SwiftUI, MVVM, async/await, Decimal для денег.

## Запуск
Открыть `Exchange.xcodeproj` → ⌘R. Ничего доп. настраивать не нужно.

## Архитектура
Model (Ticker) → ViewModel (вся логика и состояние, включая active field pattern для двустороннего ввода) → View (только отображение).

## Функционал
- Конвертация USD ↔ выбранная валюта в реальном времени, с любого поля
- Bottom sheet выбора валюты (MXN, ARS, COP, BRL, EURC)
- Swap с сохранением сумм при своих валютах
- Курс отображается сверху экрана
- Форматирование чисел (2 знака после запятой, разделители тысяч)
- Decimal pad клавиатура, парсинг с учётом локали (точка/запятая)

## Известные ограничения
- API списка валют (`tickers-currencies`) недоступен — используется fallback-список, проверенный вручную против реального API
- Список валют ограничен пятью (MXN, ARS, COP, BRL, EURC) — коды подтверждены как реально поддерживаемые сервером
